# VisualsHelper

**色觉自测 · 学习与模拟考试**

一个纯本地的色觉检查图练习工具，零依赖、零构建，双击就能跑。

## 这是什么

题库是《色觉检查图》第六版的 **48 张图版**，已提前裁切好放在 `assets/plates/`。
工具把「看图认数」这件事拆成三块：**学习页**（摆图、对答案、调补偿）、
**考试页**（模拟驾检自助机流程）、**参考页**（对照公版国际版图版）。

它只用于**自测和熟悉题型**，不能替代医院或体检机构的色觉检查。

## 快速开始

需要 Python 3（仅用于起本地服务器和读写数据文件，无第三方依赖）。

```bash
git clone git@github.com:Terie412/VisualsHelper.git
cd VisualsHelper
```

**Windows**：双击 `start.bat`

**macOS / Linux**：

```bash
python3 serve.py
```

脚本会自动挑一个空闲端口（从 `8777` 起）并打开浏览器。关掉窗口即停止服务。

> 不想装 Python 也可以直接双击 `index.html`，但会失去两个能力：
> 数据只能存在浏览器 localStorage 里；
> 红绿补偿滑块失效（浏览器判定 canvas 被跨域污染，拒绝读像素）。

## 功能

### 学习页

48 张图放在**固定的格子**里，图下面是答案，可以自由摆放和标注：

| 操作 | 行为 |
|---|---|
| 拖到格子上松手 | 卡片吸附到最近的格子。拖动时目标格显示虚框：**蓝色**空位、**橙色**已占用（松手互换），原位留虚框作提示 |
| 拖到画布边缘 | 画布自动外扩并滚动，格子没有边界，可以拖到很远 |
| 点图片 | 灯箱放大查看，带备注 |
| 点答案 | 就地改答案，存入数据文件，优先级高于 `js/data.js` |
| 「答案」开关 | 关掉后隐藏卡片下方答案，但条子和格子高度不变，布局不跳 |
| 行备注 | 每行最左侧输入框，按**行**保存，与卡片内容无关——卡片换位置，备注留在那一行 |
| 行首「不考」 | 每行左侧还有一个勾选框。勾上后**这一行的图全部不参与考试**：卡片压暗、右上角标「不考」，考试抽题时直接跳过。跟着行走，卡片拖到别的行就按新行算 |
| 改卡片尺寸 | 只改卡片大小与间距，**不重排格子坐标**；超出屏宽就横向滚动 |
| 按图号排序 | 恢复成 `001`、`002` … 的顺序 |

排列结果自动保存，下次打开还是你摆的样子。

### 红绿补偿

点开大图，右侧有一个 **0%–100%** 的滑块。

色觉检查图是**刻意做成等亮度**的：数字和背景的明暗几乎一样，差别全压在红绿轴上。
红绿色弱缺的正是这条轴，所以看到的是一片均匀噪点。

滑块把红绿轴上的差异（每像素 `R−G` 相对全图均值的偏差）按比例叠加到亮度上：

- **0%** — 原图，即色弱体检时看到的样子
- **50%** — 数字开始浮出来
- **100%** — 形状完全由红绿差异决定，谁都看得清，但图变成黑白

于是它有两种用法：色弱的人可以靠它认出内容；色觉正常的人在 0% 和 100% 之间来回拖，
能直观感到「同一张图，色弱看到的究竟是怎样的噪点」。

实现是 canvas 逐像素处理（640px 宽的工作副本），拖动时用 `requestAnimationFrame` 节流。

### 考试页

模仿驾检自助机的流程：

1. 从**有答案的题**里随机抽题并打乱（默认 12 题，可改）。
2. 一张一张出，**每张单独限时**（默认 6 秒），顶部有进度条。
3. 右侧 4 个候选答案，点击即作答并自动进下一张；键盘 `1`–`4` 也可以。
4. 超时未作答按超时处理，自动跳下一张。
5. 过程中**不提示对错**，答完统一给结果：通过 / 未通过、得分、错题列表。

候选答案里 3 个干扰项和正确答案**同类型**：数字题给数字，图形题给图形（牛、羊、蜻蜓…），
不会出现「21 / 牛 / 茶壶」这种一眼能排除的组合。

补充：不想答这张可以点「看不清 / 跳过」；`Esc` 退出；切到别的标签页会暂停计时。

**中途放弃**：左下角「放弃本次考试」，确认后直接回到准备页，本次答案作废、不生成成绩。
确认框弹出时计时会暂停，想清楚了再决定也不会被判超时；`Esc` 或点背景等同于「继续考试」。

**题库覆盖**：48 张里 46 张有答案，全部能进考试，数字题与图形题一视同仁，都是四选一。
剩下 2 张（第 22、23 张）对比度太低没标答案，暂不参与。
另外在学习页勾了「不考」的行里的图，也不参与抽题。

**设置项**（右上角齿轮）：

| 项目 | 默认 | 说明 |
|---|---|---|
| 每次抽题数量 | 12 | 从可判分的题里抽 |
| 单图限时 | 6 秒 | 时间到自动进入下一张 |
| 允许答错 | 1 张 | 错的张数超过该值判未通过 |

### 参考页

另外附了 8 张**公版**国际版 Ishihara 图版（Wellcome Collection，CC BY 4.0），
与国内第六版不是同一套，只用于对照练辨色，不参与考试。

## 目录结构

```
index.html          页面骨架
css/app.css         全部样式
js/data.js          ← 题库配置
js/store.js         本地存储（优先走 /api/data，回退 localStorage）
js/compensate.js    红绿补偿（canvas 逐像素）
js/ishihara.js      参考图库清单
js/learn.js         学习页（自由拖拽画布）
js/exam.js          考试页（抽题、计时、判分）
js/app.js           视图切换、设置
serve.py            本地服务器 + 数据读写接口
start.bat           Windows 一键启动
assets/plates/      48 张第六版图版
assets/ishihara/    8 张公版国际版图版
```

> `data/` 是运行数据（布局、答案、行勾选），随仓库一起版本化，便于换机器直接复用。
> 只把 `temp/`（整页截图原图与裁图脚本）留在 `.gitignore` 里。

## 修改题库

答案都在 `js/data.js`：

```js
plateCount: 48,          // 一共多少张
answers: {
  1: '21',               // 数字答案 → 进考试
  8: '茶壶',             // 图形答案 → 只学习
  24: '',                // 留空 → 不进考试
}
```

- 想给图形题也做考试，在 `choices` 里配选项，它就会变成按钮选择题。
- 换图：把新图放进 `assets/plates/`，按 `001.jpg` 命名，改 `plateCount` 和 `answers`。
- 也可以直接在学习页点答案条改，改完存进 `data/layout.json`。

## 数据存储

所有布局、行备注、答案、设置都存在项目下的 **`data/layout.json`** —— 一个普通 JSON 文件，
和浏览器、启动方式、清缓存都没关系。想备份就复制它，想换电脑就带着它。

服务器提供两个接口：`GET /api/data` 读、`POST /api/data` 写，前端每次改动后自动保存（防抖 220ms）。
该文件属于本机数据，已在 `.gitignore` 中排除。

**从旧版本迁移**（之前用 `file://` 双击打开过的话，只需做一次）：
双击 `index.html` → 齿轮 → 「备份到文件」，得到下载目录里的 `visuals-helper-layout.json`；
再双击 `start.bat`，`serve.py` 会发现它并自动复制成 `data/layout.json`。
若 `data/layout.json` 已存在则跳过，不会覆盖现有数据。
