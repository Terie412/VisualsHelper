这个目录不再放图版。

《色觉检查图》这类图册受版权保护，图不随仓库分发，也不在 git 历史里。

自己导入的图会存到 temp/plates/（已在 .gitignore 中）：

  1. 用 start.bat 或 python serve.py 启动
  2. 右上角齿轮 → 图版图片 → 导入图片…（可多选，只收 jpg / png / webp）
  3. 回到学习页，点卡片下方的答案条逐张标注答案

也可以手动把图按 001.jpg、002.jpg 这样命名后放进 temp/plates/。
（手动放的图仍按 js/data.js 里的内置答案显示；换成自己的图册时，请走导入按钮，
  否则会上书本的答案，可以在学习页逐张改。）

详细说明见项目根目录 README.md。
